# Portal DM para Android

Esta pasta contém uma cópia independente do Portal DM, preparada como aplicação instalável (PWA).

## O que foi preservado

- Os mesmos utilizadores e palavras-passe do portal atual.
- A mesma ligação ao Supabase e às tabelas já utilizadas.
- As funcionalidades, permissões e dados do portal original.
- O repositório original não foi alterado.

## Como instalar no Android

1. Publique esta pasta num endereço HTTPS separado.
2. Abra esse endereço no Google Chrome do telemóvel.
3. Toque no botão **Instalar Portal DM**. Se o botão não aparecer, abra o menu do Chrome e escolha **Instalar aplicação** ou **Adicionar ao ecrã principal**.
4. O ícone **Portal DM** ficará no ecrã principal e abrirá como uma aplicação.

## Computadores

No Chrome ou Edge, abra o mesmo endereço e escolha o ícone **Instalar** que aparece na barra de endereço.

## Nota

A instalação exige que a pasta esteja publicada num endereço HTTPS. A publicação deve ser feita num alojamento separado; não é necessário alterar o repositório atual.
